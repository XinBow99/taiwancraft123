# taiwan

把 Minecraft 的世界換成台灣的樣子。Fabric 模組，Minecraft 26.2。

一條中央山脈往西降成丘陵、丘陵降成沖積平原、河從山上一路切到海；聚落長在平原與河階上，
街上有騎樓、鐵皮加蓋、電線桿、鐵捲門、會發光的招牌、宮廟與夜市。

## 快速開始

### 只想玩

到 [Releases](https://github.com/XinBow99/taiwancraft123/releases) 抓 `taiwan-*.jar`，
連同 [Fabric API](https://modrinth.com/mod/fabric-api) 一起丟進 `mods/`。需要：

- Minecraft **26.2**
- Fabric Loader **0.19.3** 以上

**客戶端與伺服器兩邊都要裝。** 這不是建議，是硬性要求——機車與 8+9 註冊在
`ENTITY_TYPE`，那是會同步的 registry，沒裝的客戶端 id 表對不上就連不進來
（細節見下面的「網路相容性」）。

建立世界時「世界類型」選 **台灣**。

### 想改程式

```
git clone https://github.com/XinBow99/taiwancraft123.git
cd taiwancraft123
./gradlew runClient      # 開一個裝好模組的客戶端
./gradlew runServer      # 開一個本機伺服器（run/ 底下）
```

**需要 JDK 25。** 這是最容易卡住的一項——`build.gradle` 的 `options.release = 25`，
JDK 低於 25 會在編譯期就失敗，而錯誤訊息不會告訴你「去裝新的 JDK」。
用 `java -version` 確認；沒有的話裝 [Temurin 25](https://adoptium.net/)。

Gradle 不用另外裝，`./gradlew` 會自己抓。第一次跑要下載 Minecraft 與對應的
mapping，會花幾分鐘。

其他有用的：

```
node tools/serve.mjs                  # 模型檢視器 http://localhost:8731/
node tools/render.mjs cygnus out.png  # 把模型算成一張圖（BG=light 用白底）
node tools/engine-sound.mjs           # 重新產生引擎聲
```

## 玩

建立世界時「世界類型」選 **台灣**。專用伺服器則在 `server.properties` 寫：

```properties
level-type=taiwan:taiwan
```

`level-type` 只在世界**第一次生成**時讀取——生成器連同參數會寫進 `level.dat`，之後改
`server.properties` 不會有作用。要換就開新存檔。

### 找路

```
/taiwan locate town      # 最近的聚落
/taiwan locate temple    # 最近的宮廟
/taiwan locate market    # 最近的夜市
```

聚落選址是座標的純函數，所以這個指令**不需要地圖先跑過**，也完全不碰硬碟。

### 騎機車

兩個車款：**速克達**（`taiwan:scooter`）與**勁戰四代 125**（`taiwan:cygnus`）。
街邊會生成違停的車，右鍵直接騎走；第一個騎上去的人就是車主，別人騎不走。

| 按鍵 | 動作 |
|---|---|
| W / S | 油門 / 煞車（停住之後再按 S 是倒車） |
| A / D | 轉向 |
| 空白鍵 ＋ 轉向 | 甩尾。撐約一秒再放開，會有一段加速 |
| Shift | 下車 |

最高速 **120 km/h**（0 到 100 約五秒），左下角有指針式的儀表板。

騎進水裡會熄火，要牽上岸才發得動。

#### 物理

**這不是「按鍵就轉」，是一套動力學的自行車模型。** 車身朝向不是龍頭角度的函數，
而是輪胎力矩積分出來的：

1. 算每個輪子的**側滑角**——輪子指的方向與它實際在走的方向差幾度；
2. 側滑角乘上側滑剛度得到輪胎的側向力，超過抓地力上限就打滑；
3. 兩個輪子的力對重心取力矩，除以轉動慣量得到角加速度，積分成角速度。

差別在於這條迴路有**負回授**：車身一旦轉得比行進方向快，後輪的側滑角就變大、
產生反向力矩把車拉回來。所以放開方向鍵之後車會自己回正，不需要任何特判。

後輪的側滑剛度比前輪高（轉向不足），所以車是穩定的——推過頭只會往外滑出去，
不會原地打轉。高速過彎的半徑不是龍頭角度決定的，是**抓地力上限**決定的：
全速滿舵的幾何半徑是 10.7 格，但那需要的向心加速度超過輪胎能給的，所以輪胎先飽和、
車往外推，實際半徑落在 20 格左右。要過彎就得先減速，跟真的騎快車一樣。

甩尾（空白鍵）是把後輪的抓地力上限打到四成——鎖死的輪子側向力崩掉，車尾就滑出去。
不是額外加的轉向倍率，是同一組輪胎方程式算出來的。

#### 引擎聲

合成的，不是錄音（`tools/engine-sound.mjs`，改參數重跑就能再生一次）。
作法是**脈衝敲共振腔**：每次點火放一個不對稱的壓力脈衝，去敲五個共振器，讓它們自己
震盪衰減。最低那顆的餘韻比怠速的點火週期長九倍，所以每一發都疊在前面幾發的尾巴上——
那個重疊就是汽缸的厚度。

把一堆正弦波加起來（加法合成）頻譜可以對得很準，但聽起來是風琴不是引擎，
因為少了「被敲一下、餘韻散掉」這件事。

### 8+9

六型：廟會扛轎哥、機車少年、潮流街頭仔、地方大哥型、白衣白褲信徒、夜市兄弟團。
聚落的街上會生成，或用 `/taiwan gather [n]` 在腳邊放一團。

核心機制是**群膽**，而且帶遲滯——聚集要 3 人才算成團，但要掉到 2 人才算散掉。
用同一個門檻的話，第三個人在邊界上走來走去，整團會每個 tick 在兩個狀態之間跳。

這個旗標有四個出口，不是只改台詞：

| | 落單 | 成團 |
|---|---|---|
| 台詞 | 一組 | 換另一組 |
| 姿勢 | 三七步 | 幅度放大 1.45 倍 |
| 騎車 | 三成油門 | 全油門的車隊 |
| 音樂 | 無 | 放歌 |

他們會去牽路邊**無主**的機車（你停在門口的車不會被騎走），成群時沿著街跑。
騎車的方向是**探路**不是導航：往前方扇形探九條射線，看哪個方向的鋪面延伸得最遠。

**他們不主動打人**，只有被打才還手（打一個整團轉頭）。這是刻意的：8+9 源自八家將，
本來是廟宇陣頭——農閒時村裡男丁在廟埕練陣、練武、凝聚村里。六型全部寫成尬車嗆聲，
就只是把刻板印象再演一次。所以廟會與白衣那兩型講的是信仰。

8+9 只在區塊**第一次生成**時放進聚落，已經探索過的區域不會回填——測試用 `/taiwan gather`。

## 設計上的幾個決定

**地形只有一個「地面在哪」的來源。** 填方塊、高度圖、柱體取樣、聚落選址、生態系判定全部問
`Urban.ground`。各寫一份的話它們會慢慢對不上，而那種錯誤的症狀不是報錯，是玩家掉進地板。

**山脈是「摺」出來的，不是「疊」出來的。** 直接拿 fBm 當高程只會得到一堆饅頭。脊狀雜訊把
雜訊摺一次，摺痕落在零交越線上——那條線連續、細長、會分岔，那正是山脈的形狀。

**建築沿街排，不是填滿街廓。** 座標系是「離最近的街緣幾格」而不是「街廓內的第幾格」，
所以主幹道變寬時騎樓會自己退後。

**騎樓是不能省的那一項。** 二樓以上壓在人行道上方、一樓退進去三格、每隔一戶一根柱子。
少了它，同一排房子會讀成任何一個亞洲城市。

**招牌會發光。** 台灣街景的一半是入夜之後那些亮著的招牌。招牌文字走
`ChunkAccess.setBlockEntityNbt` 的延遲路徑——世界生成階段還沒有 `Level`，直接建
`SignBlockEntity` 再 `setText` 會 NPE。

**店名一律原創惡搞，不使用任何真實商標**（見 `ShopName.java`）。

**聚落核心區塊跳過原版生態系裝飾。** 否則樹會長在四樓的頂樓加蓋上。代價是聚落正下方沒有
礦脈——礦與樹在原版是同一個裝飾階段，介面沒有分開的餘地。

## 網路相容性

Phase 1 的地形與聚落**不需要客戶端裝模組**：`CHUNK_GENERATOR` 與 `BIOME_SOURCE` 都不在
`RegistryDataLoader.SYNCHRONIZED_REGISTRIES` 裡，客戶端收到的只有算好的方塊，而生態系用的
全是原版 id。

**獼猴、機車、8+9 一加進來，這件事就結束了**——`ENTITY_TYPE` 是同步的 registry，
`SOUND_EVENT` 也是。目前的版本**客戶端與伺服器兩邊都必須裝模組**，而且版本要一致。

## 設定

地形與聚落的參數寫在 world preset（`data/taiwan/worldgen/world_preset/taiwan.json`）的
`settings` 裡，改完開新世界生效。

參數放在 world preset 而不是 config，是因為地形是**一個世界的性質**，不是一台伺服器的偏好。
放 config 的話，同一個存檔換一台機器開就會長出對不上的地形，接縫是一道垂直的斷崖。

建築類型用權重開關，**設成 0 就是關掉那一類**：

```json
"buildings": {
  "drink_shop": 3,
  "temple": 1,
  "market": 2,
  "tenement": 8,
  "convenience": 2
}
```

## 模型工具

`tools/model-viewer.html` 用跟 `MacaqueModel.createBodyLayer()` 相同的數字，把生物從
十二個角度畫出來，並印出「模型多高、腳底停在 y 多少」。

```
node tools/serve.mjs                          # http://localhost:8731/?model=cygnus
BG=light node tools/render.mjs cygnus out.png # 算成一張圖（深色模型要白底才看得出輪廓）
node tools/check-model.mjs cygnus src/client/java/.../CygnusModel.java
```

`gen-model.mjs` 會從 `models.js` **產生** Java 的 `createBodyLayer()`，
`check-model.mjs` 則驗證兩邊一致。勁戰有四百多個零件，手抄進 Java 抄過四次、
每次都出錯（第一次就把小數尺寸全部四捨五入掉了），所以那個「一字不差」的不變式
現在是機器在維護。

**改完模型先跑它再進遊戲。** 第一版的獼猴就是靠它抓到腳底停在 y=25——在遊戲裡那是
猴子陷進土裡一格，而在網頁上那只是一行紅字。左右成對的部位、尾巴的弧度、頭身比例
這些「醜不醜」的問題，用文字描述沒有用，要看圖。
